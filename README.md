# 数形工坊（GeoMath Studio）

一个面向数学学习/教学的 **交互式数形结合工具**：把“几何作图、函数图像、推导与讲解”放在同一个画布里，并提供 AI 助手把自然语言（含图片）转成可执行的作图/绘图操作。

- **在线体验**：`http://geomath.cn:18080/`
- **状态**：本仓库为 **公开介绍页**（不包含源码）

---

## 你可以用它做什么

- **动态几何画板**：点、线（线段/直线/射线）、圆、交点/中点、标注与测量；支持拖拽交互与自动重算
- **函数图像系统**：显式/隐式函数图像渲染；支持“点贴合曲线/圆/线”等投影约束交互
- **AI 助手**：输入题目描述或截图，自动生成作图/绘图步骤并在画布中执行，便于快速搭建图形与验证直觉

---

## 适用场景

- **教学演示**：课堂动态演示几何关系、函数变化与参数影响
- **刷题与自测**：快速画出辅助线/函数图像，观察关键点与不变量
- **讲题内容制作**：用交互图代替静态图，降低讲解成本

---

## 设计要点（高层）

- **同一画布，统一对象模型**：几何对象、测量对象、函数图像都作为“可引用对象”存在，可被约束与联动
- **拖拽即推理**：拖动点时会保持其“在对象上”的约束（例如在线、圆周、函数曲线上），并实时投影回合法位置
- **AI = 操作序列生成器**：AI 输出的是“操作序列”，由前端执行并把结果回传，形成可追踪、可重放的交互流程
