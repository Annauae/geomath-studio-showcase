# 源码说明（为什么不开源）

本仓库的定位是“公开介绍与文档沉淀”，当前不公开源码，主要原因包括：

- **线上服务与安全边界**：包含账号体系、邮件验证、订阅/计费与线上运行环境等，直接公开会增加被滥用与攻击的风险面
- **工程化与依赖治理**：项目仍在快速迭代期，公开源码会带来较高的对外支持与兼容成本
- **商业与合作空间**：希望先以产品形态验证需求与体验，再逐步讨论更合适的开放策略

## 可能的开放方式（规划）

- 开放部分与业务无关的组件（例如几何/图形基础库的子集）
- 提供“教育机构/团队”的私有化部署合作
- 以插件/脚本形式开放可扩展能力（例如可自定义工具、指令或模板）

如果你对合作、试用或某一部分能力的开放有明确诉求，欢迎在 GitHub Issues 里说明你的使用场景与需求。
