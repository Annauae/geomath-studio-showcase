# Source code availability (why it’s not open-source)

[中文](SOURCE_CODE.md) | **English**

This repository is meant for public documentation and project introduction. The source code is not published at the moment, mainly because:

- **Security boundary for an online service**: accounts, email verification, subscriptions/billing, and production operations increase risk when fully exposed
- **Fast iteration phase**: open-sourcing too early can create high external support and compatibility costs
- **Room for collaboration/commercialization**: we want to validate product experience first and choose a healthier open strategy later

## Possible future directions

- Open-source selected components that are unrelated to business logic (e.g. parts of the geometry/graph engine)
- Offer private deployments for schools/teams
- Provide extensibility via plugins/scripts/templates

If you have a concrete collaboration or deployment need, feel free to open a GitHub Issue describing your use case.
