# 架构概览（公开版）

## 总体形态

系统可分为三层：

1. **Web 前端（画布与交互）**
   - 负责几何对象/函数图像的渲染
   - 负责拖拽交互、约束投影、自动重算
   - 负责把 AI 生成的“操作序列”落地执行

2. **后端服务（账号/订阅/AI 调度）**
   - 负责用户体系与权限
   - 负责订阅/计费相关的业务编排（对接支付网关等）
   - 负责 AI 对话编排与工具调用（把“当前画布状态 + 规则/提示”组织成上下文）

3. **模型服务（AI 推理）**
   - 接收后端构造的上下文与用户输入
   - 返回结构化的操作指令（由前端执行）

## 数据流（简化）

- 用户在画布上操作 → 前端更新画布状态
- 用户唤起 AI → 前端上传当前画布状态与输入
- 后端组织上下文并请求模型 → 获得“操作序列”
- 前端按序执行操作 → 将执行结果回传后端（用于继续对话或生成下一步）

## 关键设计点

- **对象模型统一**：几何对象、测量对象、函数图像等都可被引用与约束，便于组合表达
- **约束投影**：点可以被约束在某个对象上（如直线/线段/圆/曲线）；拖动时通过投影保持约束成立
- **可重放**：AI 产物是操作序列而非“直接画图结果”，便于审计、撤销/重做与复现
