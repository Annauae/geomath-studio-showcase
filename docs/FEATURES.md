# 功能说明（公开版）

本页只描述可公开的产品能力与交互特性，不包含内部接口、私有配置与实现细节。

## 1. 动态几何画板

- **基础对象**：点、线（线段/直线/射线）、圆
- **派生对象**：交点、中点（由已有对象计算得到）
- **辅助表达**：文本标注、距离/角度测量
- **交互体验**：
  - 拖拽点/对象，画面实时更新
  - 依赖关系自动重算（例如交点随两条线变化而更新）

## 2. 函数图像系统

- **图像类型**：显式函数、隐式函数等常见形式
- **交互能力**：
  - 在图像附近创建点，并让点“贴合”到曲线上
  - 拖动点时保持约束，点会自动回到曲线/圆/直线等对象上

## 3. AI 助手（作图/绘图自动化）

- **输入**：文本题目描述；可扩展到图片/截图场景
- **输出**：可执行的“操作序列”（例如创建对象、在对象上取点、绘制函数图像、添加标注/测量）
- **价值**：
  - 快速搭建题图，降低从“读题”到“动手作图”的摩擦
  - 把隐含的作图步骤显式化，便于复盘与教学讲解

## 4. 账号与订阅（概览）

项目包含常见的账号体系（如邮箱验证登录/找回）与订阅能力，用于区分基础功能与增强能力的可用范围。
