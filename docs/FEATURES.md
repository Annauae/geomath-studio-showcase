# 功能与玩法

**中文** | [English](FEATURES.en.md)

你可以把 GeoMath Studio 当成一个“可拖拽、可约束、可复现”的数学画布：既能画几何，也能画函数，还能让 AI 帮你把题目快速变成可操作的图。

## 动态几何（拖拽会自动重算）

- **常用对象**：点、线（线段/直线/射线）、圆
- **自动生成**：交点、中点（跟随依赖对象变化）
- **表达工具**：文本标注、距离/角度测量
- **你会明显感受到的体验**：
  - 拖动任意点，关联对象会立刻更新
  - 图形关系不靠“手画”，而靠对象之间的依赖关系保持成立

## 函数图像（把“曲线”当成对象）

- **支持类型**：常见的显式/隐式函数图像
- **典型用法**：
  - 画出曲线后，在曲线附近放一个点
  - 让这个点“贴合曲线”，再拖动它观察变化（不会拖离曲线）

## 约束与贴合（点会自动回到正确位置）

当一个点被设置为“在某个对象上”（直线/线段/圆/函数曲线），你拖它的时候它会自动投影回目标对象。

这对解题很有用：你可以放心拖动去“找规律”，而不是担心图形关系被你拖坏了。

## AI 作图助手（把一句话变成操作步骤）

- **你输入**：一句话描述目标图形（也可以是题目/截图场景）
- **它输出**：一串可执行的作图步骤（创建点/线/圆/函数图像、在对象上取点、添加标注/测量等）
- **你得到**：
  - 更快的起图速度（从“读题”到“有图”）
  - 可复盘的过程（每一步都能看、能改、能继续）
