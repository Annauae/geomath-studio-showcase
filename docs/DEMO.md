# 演示与使用建议

## 在线体验

演示站点：`http://geomath.cn:18080/`

> 提示：演示环境仅用于功能展示与稳定性观察，请勿输入敏感个人信息。

## 建议的演示顺序（3–5 分钟）

1. **动态几何**
   - 创建若干点与线/圆
   - 构造交点/中点
   - 拖动点，观察依赖对象实时变化

2. **函数图像**
   - 绘制一个典型函数图像（如圆、抛物线、三角函数等）
   - 在图像上放置一个点并拖动，观察“贴合曲线”的约束效果

3. **AI 助手**
   - 输入一句自然语言的作图目标（例如：画一个圆，并在圆上取点再连线）
   - 观察 AI 输出并执行的步骤，确认图形与目标一致
