# Get started in 3–5 minutes (suggested flow)

[中文](DEMO.md) | **English**

Live demo: `http://geomath.cn:18080/`

## 1) Feel “drag → instant recompute” (~1 min)

- Create a few points
- Connect them with segments/lines, then add a circle
- Build an intersection or a midpoint
- **Drag one point** and watch intersections/midpoints/measurements update live

The key feeling: your diagram is not “static”; relationships stay valid while you explore.

## 2) Try “point sticks to curve” (~1 min)

- Plot any function graph you like
- Place a point near the curve and make it “stick” to the curve
- Drag the point—it won’t leave the curve

This “stick to object” workflow also applies to lines/segments/circles.

## 3) Use AI to bootstrap a diagram (~1–3 min)

In the AI panel, try a sentence like:

- “Draw a circle, pick two points A and B on it, connect AB, and label the chord length.”
- “Plot \(y=x^2\). Pick a point P on the curve, drop a perpendicular to the x-axis, and label the distance.”

Then:

- Watch the generated steps being executed
- If anything is off, just drag/adjust manually and continue from there
